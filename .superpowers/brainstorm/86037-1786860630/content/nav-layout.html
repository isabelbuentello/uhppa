Navigation Header — Mobile Adaptation

How the top nav collapses across breakpoints

A

Hamburger Menu

Below 768px, nav links collapse into a hamburger icon (☰). Tapping opens a full-screen overlay with stacked links. The logo and login/logout stay visible.

Tap ☰ → full screen overlay with stacked nav links
B

Scrollable Nav Row

Nav stays visible as a horizontally scrollable row. No hamburger, no hidden content. User swipes left/right to see all tabs. Simpler, but some links may be off-screen.
