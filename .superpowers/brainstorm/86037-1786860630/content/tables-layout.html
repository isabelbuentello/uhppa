Data Tables — Mobile Adaptation

Admin tables have 5-7 columns. How should they work on a phone?

A

Horizontal Scroll

Wrap each table in a horizontally scrollable container. The table keeps its full desktop layout — user swipes left/right to see all columns. Simple, preserves layout, familiar pattern (like spreadsheets on mobile).
