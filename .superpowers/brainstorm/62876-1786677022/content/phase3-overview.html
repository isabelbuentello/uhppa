Firestore Collections

Collection Purpose Key Fields
pointsLedger/{id} Every points entry memberId, eventId, points, category, semester, method (checkin/request), status (verified/pending)
slides/{id} Slide deck metadata title, date, tag, year, pageCount, fileSize, storageUrl, downloadUrl
events/{id} (modified) Add check-in code + checkinCode (string, optional)
clubInfo/main (modified) How points work + pointsGuide (string)

Pages

Points Tracker

  • Total + progress bar (semester goal)
  • Category breakdown cards
  • "How points work" collapsible
  • Activity log table
  • Check-in code form
  • Submit missing points form

Slides Archive

  • Search by title
  • Year filter buttons
  • Card grid with metadata
  • Download from Firebase Storage
  • Upload deferred to Phase 4

Leaderboard

  • Scope: Semester / Monthly / All-Time
  • Top 3 podium
  • Ranked table (4+)
  • Current user highlighted
  • Client-side aggregation

Key Decisions

  • Points claiming: Check-in code (instant) + manual request (officer-reviewed)
  • Semester: Auto-derived from date (Aug–Dec = Fall, Jan–May = Spring, Jun–Jul = Summer)
  • Leaderboard: Client-side aggregation, optimize later if needed
  • RSVP: Deferred (noted for future phase)
  • Slides upload: Phase 4 (officer tools), Phase 3 builds the viewer only
